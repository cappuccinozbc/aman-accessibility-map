# 修改说明 (2025-02-22)

## 修改内容

### 1. 中心点位置可选择并显示

**问题：** 中心点位置不可选择，也没有在地图上显示

**解决方案：**
- 添加了"在地图上选择中心点"按钮
- 点击按钮后，可以在地图上任意位置点击来设置中心点
- 中心点会在地图上以蓝色标记显示，带有信息窗口
- 中心点标记使用高德地图的标准标记图标

**新增功能：**
- `startSelectCenterPoint()`: 开始选择中心点模式
- `setCenterPoint(lng, lat)`: 设置中心点并在地图上显示标记
- `centerPointMarker`: 中心点标记变量
- `isSelectingCenterPoint`: 选择模式标志变量

### 2. 可达范围结果改为边界线

**问题：** 可达范围结果显示为填充的多边形

**解决方案：**
- 将可达范围从填充的多边形（Polygon）改为边界线（Polyline）
- 使用 Graham 扫描算法计算凸包，确保边界线正确显示
- 边界线使用橙色，线宽为 3px，更加醒目

**算法实现：**
- `calculateConvexHull(nodes)`: Graham 扫描算法计算凸包
- `crossProduct(p0, p1, p2)`: 向量叉积，用于判断点的位置关系
- `distance(p1, p2)`: 两点距离平方，用于排序

## 使用方法

### 选择中心点
1. 点击左侧面板的"📍 在地图上选择中心点"按钮
2. 在地图上点击任意位置
3. 中心点会在地图上显示，同时更新经纬度输入框

### 查看可达范围边界线
1. 确保中心点已设置
2. 设置步行时间（默认10分钟）
3. 点击"搜索可达范围"按钮
4. 可达范围会以橙色边界线的形式显示在地图上

## 技术细节

### Graham 扫描算法
1. 找到Y坐标最小的点作为起始点
2. 根据极角对所有点进行排序
3. 使用栈结构维护凸包上的点
4. 通过叉积判断点是否在凸包上
5. 最终得到凸包的所有边界点

### 中心点标记
- 使用高德地图的标准标记图标
- 添加了信息窗口显示坐标
- 设置了高层级确保不被其他标记遮挡
